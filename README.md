# PowerSDR / FLEX-5000 — SQ4KOU

Dedykowane repozytorium dla prac związanych z FLEX-5000 i PowerSDR/Thetis-FLEX5000.

## Struktura gałęzi

- `baseline/flex5000-wdsp-native` — linia natywnego WDSP/FLEX-5000.
- `archive/flex5000-hpsdr-isolation-fix` — wcześniejszy etap izolacji HPSDR NetworkIO.
- `feature/powersdr-flex5000-display` — prace nad widokiem/display PowerSDR.
- `feature/powersdr-flex5000-thetis-ui` — prace nad interfejsem Thetis przenoszonym do PowerSDR.

Gałąź `main` służy jako indeks projektu. Nie jest automatycznie uznawana za sprzętowo potwierdzony punkt PASS.

Źródłowe gałęzie zostały przeniesione z `SQ4KOU/SQ4KOU-THETIS` z zachowaniem historii Git.
